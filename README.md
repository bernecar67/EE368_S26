# EE368_S26

To properly run this project you need to download all files in the repo into one folder
Next you want to run these sql commands:
```
DROP DATABASE IF EXISTS ee368_oauth;
CREATE DATABASE ee368_oauth;
```
After that you are going to to run this python command in your Visual Studio Code terminal:
```
pip install -r requirements.txt
```
After that you will run app.py in it's own terminal.
```
python app.py
```
Finally you will run main.py in its own terminal and proceed to the local url provided from main.py
```
python main.py
```
